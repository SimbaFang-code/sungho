# 서린대학교 大学背景 BOYNEXTDOOR 手机模拟器

韩国大学背景 iPhone 手机模拟器校园甜宠固定主线。

## 项目简介
- 虚构大学 서린대학교（西凛大学）
- 玩家为大一新生，六位 BOYNEXTDOOR 成员为虚构校园 AU 中的大三学长
- 唯一恋爱主线：朴成淏
- 其余五位为朋友型学长学妹关系
